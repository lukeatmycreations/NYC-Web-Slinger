# NYC Web Swinger

A fast-paced, physics-based 2D web-swinging game built with HTML5 Canvas and JavaScript. Race against an AI rival through dynamic cityscapes, unlock new suits, and master momentum-based swinging on desktop or mobile.

🎮 **[Play the Live Demo](https://lukeatmycreations.github.io/nyc-web-slinger)**

---

### Features

* **Physics-Based Swinging:** Real-time pendulum mechanics and momentum-driven movement.
* **100 Collectible Suits:** Win races against the AI rival to unlock new suits.
* **Dynamic Environments:** Choose between Midtown Manhattan, Central Park, and Cyber-NYC 2099.
* **Multiple Difficulties:** Adjustable AI speed (Super Easy, Easy, Medium, Hard).
* **Mobile Ready:** On-screen touch controls optimized for smartphones and tablets.
* **Zero Dependencies:** Pure HTML5, CSS, and vanilla JavaScript—no frameworks or build steps required.
